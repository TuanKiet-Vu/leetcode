# Balanced Binary Tree

## Problem
Given a binary tree, determine if it is height-balanced.

## Pattern

Trees

## Idea
- Traverse the tree to find it's height
- To determine if the branch is balanced by abs(right-left); If it's not balanced return -1
- When we reach the root, if the height of the left or right side is -1, return -1 (the tree is not balanced



## Complexity

Time complexity: O(n)

Space complexity: O(n)
